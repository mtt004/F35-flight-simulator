# Appearance packs

Import JSON from Graphics → Appearance pack. Schema 1 accepts only id, name, three #RRGGBB colours and descriptive metadata. Max file size 16 KiB; no scripts, URLs or assets are loaded. These are authored palettes for the seeded world, **not geographic scenery**. Hampshire and Cappadocia elevation/airport packs remain unimplemented; see docs/scenery-data.md.
