# Project Lightning — F-35B Mobile Simulator

Offline F-35B simulator based on the owner-supplied standalone HTML. Target: Samsung Galaxy A51 (SM-A515F). Engineering started 27 October 2026 (Europe/Istanbul).

Implementation is in progress. No Android installation or Galaxy A51 performance claims have been made. The original will be preserved under `legacy/`, with checksum and provenance under `docs/`.

All source, research, build configuration and verification evidence belong in this private repository. Distributable builds belong in Releases.
