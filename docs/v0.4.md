## Rebuild pipeline

Use Python 3.12 with the immutable libraries in `scripts/london-requirements.txt`. Run these in order from the repository root, after `npm ci`:

```sh
python3 -m venv .tmp/london-venv
.tmp/london-venv/bin/pip install -r scripts/london-requirements.txt
.tmp/london-venv/bin/python scripts/build-london.py
.tmp/london-venv/bin/python scripts/build-london-ground.py
.tmp/london-venv/bin/python scripts/build-london-imagery.py
.tmp/london-venv/bin/python scripts/build-london-heights.py
.tmp/london-venv/bin/python scripts/test-london-heights.py
npm test
npm run build
```

All three CI workflows follow this sequence. The complete imagery tile set and compressed height overlay must be generated before the bundler runs. Committed scripts, OS/Sentinel SHA pins and the EA 2022 composite dataset identifiers are the inputs; the first height build records its raster byte pins in `sources.json`. Missing outputs are not replaced with placeholder artwork. The bundler verifies manifest hashes before embedding the resulting packs for offline play.

The London base pack's ordered building footprints are the identity input for the height overlay. Its input SHA is recorded in the height manifest. Do not apply an overlay to an independently changed footprint list.

## Imagery

`scripts/build-london-imagery.py` downloads three SHA-pinned Sentinel-2 true-colour COGs (approximately 751 MB combined) into `.tmp/london-sentinel-tci.tif`, `.tmp/london-sentinel-june-tci.tif` and `.tmp/london-sentinel-east-tci.tif`. It reprojects native 10 m imagery to EPSG:27700 bounds E502000–541000, N170000–185000, fills only missing source-edge pixels and writes a 2048×1024 overview plus 24 aligned 512×512 JPEG tiles. Top is north/minimum game z. All tiles share one resampling grid. Their display dimensions do not increase the 10 m source resolution.

The primary scene is 2025-08-17 (97.78% of native crop pixels); west/east edges use 2025-06-19 and 2025-08-25. `manifest.json` records exact contributions, URLs, original SHA pins, derivative hashes and software versions. STAC snapshots and `NOTICE.txt` retain provenance and the required “Contains modified Copernicus Sentinel data [2025]” attribution. `node --test tests/unit/london-imagery.test.mjs` validates the generated pack.

## Heights

`scripts/build-london-heights.py` uses the EA 2022 composite last-return DSM minus DTM at native 1 m resolution, sampled inside each OS footprint. Raw rasters are cached in `.tmp/london-lidar`. On a rebuild retaining `sources.json`, upstream byte changes fail the SHA checks; a fresh build records the 2022 dataset inputs and includes their pins in the release pack. The pipeline records applicable input survey dates, sample support and confidence. The previous generated overlay contained 38,914 measured records and 1,086 explicit footprint-heuristic fallbacks; each generated manifest records the current build’s actual counts. No fallback is labelled measured.

The estimator rejects isolated high returns without imposing an arbitrary height ceiling. Majority vegetation, temporal mismatch and complex roofs can still introduce error. Recorded uncertainty describes roof spread, not a calibrated confidence interval. Seven synthetic estimator/alignment tests run in the preprocessing virtual environment.

Keep `sources.json`, `survey-index.json`, `NOTICE.txt`, `manifest.json` and `heights.json.gz` in the generated height pack. The local uncompressed `heights.json` and raw rasters are preprocessing intermediates, excluded from scenery/evidence ZIPs. On disposable GitHub-hosted runners, a scoped workflow step deletes only `.tmp/london-lidar` and the three named Sentinel TIFF caches after successful preprocessing/tests. It preserves every processed scenery pack and `.tmp/london` OS archives for release source packaging. Local caches are retained for repeat builds.
