# Controls

Use the existing Help panel for keyboard/gamepad bindings. Touch: left/right layout selector, stick, throttle, rudder pedals/slider, gear, STOVL, brakes, AP and camera buttons. Existing gyro toggle/calibration is optional.

Settings → Lightning graphics & camera adds four profiles, camera tracking/distance/movement, military/minimal/landing symbology, procedural world appearance, JSON palette import, stick offsets and opacity, plus the performance overlay. Existing sensitivity/dead zone/scale/handedness settings remain. Changes persist locally.

Camera C cycles chase/cockpit/orbit/distant/fly-by. Additional tracking mode applies outside cockpit. Fixed mode anchors the viewpoint until mode changes; precision and cinematic track the aircraft. Graphics default is Balanced30FPS. High FPS requests60; hardware may render slower.

Backgrounding, focus loss or graphics loss saves and pauses the flight. Return and explicitly press Resume. No hidden catch-up period is simulated.
