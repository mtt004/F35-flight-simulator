# Fixed visual comparisons

All images are actual simulator WebGL captures. Before uses V2 product web source (HTML SHA256 8529330d53723356463319a96469da80fb9fc87a48ce5449abd1f47b59ed56f4). After uses London mode. The same geographic coordinates and camera are used for world views; V2 has no London geography. Aircraft close-ups use matched normal PARK spawns and relative cameras. Seed4201,1280×720,Balanced Q1,CAVOK; hour13.2 except sunset18.1/night23.3. Physics is paused for repeatable poses. These are visual inspections, not continuous-flight or device-performance evidence.

V2 contains unrelated synthetic terrain at these map positions; some fixed cameras are below its generated mountains. Such frames show absent geography, not a fair above-ground rendering-quality comparison. Preserved original V2 evidence is also available in [the existing V2 aircraft captures](../screenshots/aircraft-v0.2/v020-after/).
